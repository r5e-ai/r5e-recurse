# Contributing

Recurse is public but not yet accepting outside contributions: the
contributor agreement (CLA on the AGPL repos; none ever on the Apache
protocol surface) lands before the first external patch. Until then, issues
are welcome, forks are free, and merge requests will be closed with thanks.

How changes will enter once the gate opens: through r5e itself. A change to
Recurse is admitted like anything else — proposed, reviewed independently,
recorded on the append-only log. Nothing about Recurse gets to skip Recurse.
